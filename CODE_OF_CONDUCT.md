# Code of Conduct

## Our Standard

VoiceGuard is a collaborative engineering and research project. Contributors are expected to communicate respectfully, review technical work constructively, and keep project decisions grounded in evidence.

## Expected Behavior

- Be respectful and professional.
- Give constructive technical feedback.
- Document important decisions.
- Distinguish verified results from experiments and plans.
- Protect project data, privacy, and provenance.
- Ask before making changes that affect protected datasets or evaluation methodology.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, deliberate misinformation, fabricated experimental results, unauthorized disclosure of protected data, and intentional compromise of project integrity are not acceptable.

## Reporting

Concerns should be raised privately with the project lead or through the repository's available GitHub reporting mechanisms. Do not disclose sensitive recordings, credentials, or personal information in public issues.

## Scope

This code of conduct applies to repository contributions, issues, pull requests, reviews, and project collaboration related to VoiceGuard.
