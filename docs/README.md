# VoiceGuard Documentation

This directory contains project documentation separated by engineering concern.

- [`architecture/`](architecture/) — system and model architecture
- [`dataset/`](dataset/) — dataset scope, schema, provenance, and lineage
- [`robustness/`](robustness/) — environmental/acoustic robustness methodology
- [`evaluation/`](evaluation/) — evaluation methodology and reporting rules
- [`api/`](api/) — planned integration/API boundary

Documentation distinguishes implemented and verified work from pending and planned work.
